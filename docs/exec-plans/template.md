## 按需加入的章节

以下是填写提示，不必整段复制到每个任务：

- **Roadmap/返工**：阶段与子项目、Roadmap ID、返工来源链接；完成后回写叶子与父级状态。
- **并行与隔离**：Batch ID、显式依赖、共享接口及冻结依据、任务分支/worktree、集成分支、获批本地 Git 操作、写入边界；集成验证报告。
- **功能与工具**：功能 → feature slug → `source/tests/code/{unit,contract,integration,fixtures}/` 与按需 `source/tests/ai/` → 合同标准映射；预期正常/错误/边界行为；实际技术栈、linter 配置及命令、测试框架、定向与完整测试入口。
- **Agent 派发**：仅 Planner/Developer/Validator；角色/任务 ID、目标与合同、风险、模型/推理档位及理由、平台支持、允许/禁止写入、门禁、产物；每次均记录全新无聊天上下文，不绑定具体模型，不用换 Agent 清零失败。
- **失败与诊断**：按任务+合同版本+失败特征记录关联标准、Loop、实质不同修法、证据、计数与结果；两种实质修法仍失败、三轮不收敛或直接合同冲突时停止，由 Main 保存证据摘要、阻塞类型、用户决定及恢复条件，不派第四角色、不自动诊断后修复。
- **决策与发现**：范围内决策、未知项、仅人工可批准的变更候选。
- **交付回写**：按执行协议完成独立验证、Main 实际验收和适用获批交付后归档，清理 memory 指针；有 Roadmap 则回写链接和父级状态；只记录实际结果，不预填成功。轻量只读任务沿用其适用豁免。
