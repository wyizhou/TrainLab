# 已完成执行计划

仅保存按[执行协议](../README.md#生命周期与归档)结束的 `completed` 或明确终止的 `cancelled` 计划。当前串行正式任务需独立 PASS、Main 实际验收及完成适用获批交付；实际并行还需任务级及集成级 PASS 和对应 Main 验收。只读检查点计划依据其适用检查和实际证据结束。

Main 负责归档及真实状态回写，Planner、Developer、Validator 不接管协调状态。已有决策、派发、失败、验证和迭代原文保持不变；历史完成方式仅存证，不作为当前任务授权或验收证据。返工新建计划并重新验证，不改写旧归档，也不把历史旧角色恢复为当前流程。
