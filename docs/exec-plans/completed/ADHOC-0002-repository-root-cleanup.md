## 决策与发现

- `dist/` 是 4.1 MB 的未跟踪、已忽略构建输出；移除不会删除源码，按需构建仍可重建。
- `THIRD_PARTY_NOTICES.md` 保存 agentForge MIT 许可归属和免责声明；适配了其脚手架时应保留。
- `test_data/` 含 10 个 FIT 与 2 个其他本地文件，7 个 Garmin 测试模块直接读取；当前删除会破坏测试。
- `scripts/` 有 7 个 Python 入口，其中 6 个被 CI、README、runbook 或测试直接引用；
  `prepare_garmin_smoke_backup.py` 没有仓库内直接调用方，但仍是 E-04 隔离备份的独立命令入口，
  是否移除属于功能取舍。目录整体暂时保留，其中 `__pycache__` 可清理。
- 根 `data.db` 是 0 字节、0644 的已忽略空文件；正式数据合同指向 `state/data.db`，该空文件可在用户确认后删除。
- 根 `core` 是约 9.6 MB 的 Gmail MCP Node 进程崩溃转储，未读取内容；可能包含进程内敏感信息，建议优先删除。
- `build/` 是约 3.1 MB 的 wheel 中间产物，可安全删除并按需重建。
- `tools/` 当前只有白名单发布构建器（及可删除缓存），由 CI 和打包测试直接引用，应保留，除非用户决定彻底取消发布构建能力。
- 第一次独立 Validator 对清理动作未发现误删，但因测试依赖数和 scripts 直接引用数不准确返回
  `FAIL`；上述两项已按独立证据修正，需换新 Validator。
