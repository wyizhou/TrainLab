# Codex 三阶段开发流程

TrainLab 不再运行三个独立 AI 角色。每个开发任务按“规划 → 实现 → 验收”连续推进，阶段是质量检查点，不是三套身份和权限。

```text
用户需求
  → 规划：范围、风险、验收标准
  → 实现：代码、测试、必要文档
  → 验收：自动门禁、浏览器和视觉核对
  → 交付
```

普通任务在一个 Codex 任务内完成全部阶段。只有大型改动或用户明确要求时，验收阶段才交给独立复核任务。

- `01-planning.md`：如何把需求变成可执行范围。
- `02-implementation.md`：如何在现有工程内完成实现。
- `03-validation.md`：如何证明结果满足功能和视觉标准。
