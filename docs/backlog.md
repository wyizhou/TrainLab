# TrainLab 产品待办

本文件是普通产品待办，不再承担 Planner / Executor / Validator 状态机。具体开发任务由当前用户要求和 Codex 任务计划确定。

## 当前产品边界与规则

- 仓库已分为 `frontend/` 和 `backend/`；后端基础使用 Python 3.12、FastAPI、PostgreSQL 与 Docker Compose。
- 登录、会话恢复和退出已经接入真实后端。同步、下载、AI 回复、设置测试连接等仍默认不发起真实网络请求；接入这些真实服务必须另行确认。
- 当前登录可用条件：账号和密码均大于 6 位，且验证码正确。
- UI 设计输入由用户在每个任务中提供仓库外路径，只读使用；仓库只记录项目标识、版本、修订号和内容摘要，不保存本机绝对路径。
