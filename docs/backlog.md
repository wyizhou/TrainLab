# TrainLab 产品待办

本文件是普通产品待办，不再承担 Planner / Executor / Validator 状态机。具体开发任务由当前用户要求和 Codex 任务计划确定。

## 当前产品边界与规则

- 仓库已分为 `frontend/` 和 `backend/`；后端基础使用 Python 3.12、FastAPI、PostgreSQL 与 Docker Compose。
- 登录、会话恢复、退出和登录用户的本地 FIT 上传/列表/详情/原文件下载已经接入真实后端。佳明同步、批量下载、AI 回复、设置测试连接和 TCX/GPX 后端导入仍不发起真实外部调用；接入必须另行确认。
- 当前登录规则保持为账号和密码均大于 6 位且验证码正确；本机开发默认凭据固定为 `useradmin / useradmin`，完整规则见 `docs/runbooks/local-development.md`。该公开凭据仅允许在 `development` 环境显式配置，生产环境禁止使用。
- UI 设计输入由用户在每个任务中提供仓库外路径，只读使用；仓库只记录项目标识、版本、修订号和内容摘要，不保存本机绝对路径。
