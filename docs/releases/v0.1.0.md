- 产品版本：`v0.1.0`
- 当前状态：本地完整发布候选门禁已通过，等待最终独立复核和 GitHub PR 检查；尚未合并、打 tag 或创建 GitHub Release

- 后端组件基线：v0.3 / package `0.3.0`
- 数据库迁移头：`0003_activity_data_lifecycle`

## 发布定位

v0.1.0 是 TrainLab 首个正式产品版本号。它把已经验收的 v3.4 通用运动详情与后端 v0.3 用户归属数据能力封装为可重复安装、可本机运维、可双卷备份恢复的本地产品。组件版本保留各自演进历史，不改写成产品版本。

正式发布仍需：最终独立 Validator PASS → PR checks 通过 → 合并到 `main` → 主协调任务创建 `v0.1.0` tag 和 GitHub Release。仓库中存在本文件不表示这些动作已经完成。

## 支持范围

- 本机账号登录、Cookie 会话恢复和退出。
- 登录用户上传本地 FIT；活动、解析结果和私有原文件持久化。
- 运动列表、v3.4 共用详情、原文件下载、活动重命名、导入记录、可恢复删除和存储配额。
- 服务器 CLI 首次创建 owner、重置指定用户密码、撤销指定用户全部会话和孤儿文件审计。
- PostgreSQL 与私有 FIT 命名卷的同停写点备份、严格校验、破坏性恢复和恢复后全会话撤销。
- backend 重建和重复 owner 初始化保持数据且不产生重复记录。
- Compose 仅绑定 `127.0.0.1:8000` 的本机 HTTP 运行方式。

## 明确不支持

- Garmin Connect、TCX/GPX 后端导入、真实 AI 或其他外部同步。
- 浏览器忘记密码、会话管理或新的生命周期 UI。
- 公网暴露、TLS 终止、高可用、在线不停写备份或跨主机灾备。
- Redis、队列、后台任务或微服务。
- 使用 Alembic downgrade 作为含用户数据版本的回滚方法。

## 安装与首次运行

需要 Docker 和 Docker Compose。在仓库根目录执行：

```bash
backend/scripts/compose.sh up --build -d db backend
backend/scripts/compose.sh exec backend trainlab create-owner --username owner-user
```

输入长度大于 6 的账号和密码后访问 `http://localhost:8000/`。此地址只监听回环接口；不要通过修改绑定地址把当前版本直接暴露到公网。

## 运维入口

```bash
# 隐藏交互式重置密码，并撤销该用户全部会话
backend/scripts/compose.sh exec backend trainlab reset-password --username owner-user

# 不改变密码，仅幂等撤销该用户全部会话
backend/scripts/compose.sh exec backend trainlab revoke-sessions --username owner-user

# 创建权限收紧的备份父目录，再创建同停写点双卷备份
mkdir -p backups
chmod 700 backups
python3 backend/scripts/backup_release.py \
  --project trainlab \
  --output backups/trainlab-v0.1.0-before-change

# 校验后破坏性恢复；确认字符串必须精确匹配项目名
python3 backend/scripts/restore_release.py \
  --project trainlab \
  --backup backups/trainlab-v0.1.0-before-change \
  --confirm RESTORE:trainlab
```

不要猜测或用测试密码覆盖现有 owner。实际 owner 密码不可从数据库哈希恢复；需要时由操作者在本机终端运行重置命令。完整步骤见 `docs/runbooks/local-development.md` 和 `docs/runbooks/backup-restore.md`。

## 回滚

发布前必须创建并离线保护 PostgreSQL dump、私有 FIT 卷归档和 manifest 的完整目录。需要回滚时切回兼容代码，再用恢复工具覆盖两个卷；工具会撤销备份中的全部旧会话。只恢复数据库、只恢复私有卷或直接对真实数据运行 Alembic downgrade 都不是受支持的回滚。
