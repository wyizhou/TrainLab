机器格式：
1. 根对象只能包含 Schema 声明的决策字段；不得输出 period、date、status、provider_calls、external_actions 或其他 Host 已知字段。

3. running 与 climbing 课程的 steps 必须是对象，并完整包含 warmup、main、recovery、cooldown；每项都必须包含 name、instruction、end_condition。
4. rest 课程的 steps 必须是对象，并且只包含 checklist；checklist 必须包含 name、instruction、end_condition。
5. 课程类别与 session_type 必须匹配 Schema；不得用自由数组替代上述结构。

业务规则：
1. training_goal 是 Host 从用户目标模板确定性解析出的结构化业务数据。只能使用其中已有字段和值，不得推断缺失内容、文件名或路径。
2. 活动覆盖日期、睡眠醒来日覆盖日期和下周计划日期是三套不同日期；Host 会确定性写入这些日期，模型不得回显或改写。
3. 复盘全部实际活动，包括计划外活动。计划对比只能是简短的次要背景，不能过滤活动或成为下周计划唯一依据。
