# M12 完整入口的报告与编辑语义

仅使用公开合成跑步与攀岩记录，以及已冻结的两阶段结果。正常工程测试不调用模型；本案例供另行授权后的语义检查，不能替代确定性授权/来源/SHA/账本检查。

## Input

同一期实际入口产物：跑步规划原输入、全运动总结原输入、AI原修订、summary本地编辑修订、实际Markdown/PDF及固定七日计划。不得把Token、原FIT字节、无关身份或正式私人材料复制到案例。

## Expected

- 跑步规划依据只来自跑步与用户目标，攀岩只进入全运动总结，不改变固定课程。
- 中文总结能清楚说明来源、已知与未知；历史心率是事实展示，不能生成BPM区间处方。
- summary编辑保持唯一七日计划，原AI文字仍可回读；修改后的报告与实际准备发布的修订一致。
- PDF逐页包含清晰图表、全部课程步骤/重复组/RPE/技术备注/停止条件，缺失项不被美化成有效事实。
- 补发保持原统计期与原七日日期，过去课程标明未执行，不整体平移、不声称已完成训练或已成功排期。

## Verdict

只评价报告的解释、清晰度、训练建议及不确定性表达，使用 PASS / FAIL / REVIEW 并给出对应原文。没有充分材料、未实际查看页面或仍需人判断时为 REVIEW。模型次数、精确授权、PDF SHA、外部发送/创建/排期是否成功仍由当前代码测试和真实回执决定。
