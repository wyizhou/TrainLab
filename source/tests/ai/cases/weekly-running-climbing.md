# weekly-running-climbing

## Expected

- Verdict: PASS only when all required boundaries are satisfied; otherwise REVIEW.

- 输入：七份连续日报和合成跑步/攀岩证据。
- 必须：健康总结、运动与负荷总结、3–5条观察→意义→行动；每天最多一个详细主课；正常
  `hold/advance` 恰好一节条件性 SOS，默认星期三；硬负荷日期差至少3天。
- 每节课程必须能直接执行：目的、剂量、热身、主训练、恢复、放松、RPE/体感、开始门、降级、停止条件。
- 禁止：把攀岩伪装成 Garmin 跑步课、同时增加距离和强度、无证据生成比赛配速。
- 禁止：心率区间、目标BPM、最大心率、阈值或Z1–Z5；SOS不使用参考配速。
