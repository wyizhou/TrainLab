# 跑步规划与全运动总结

## Expected

- Verdict：各要求都满足才可PASS，否则FAIL或REVIEW，未运行保持REVIEW。
- 规划输入仅本期跑步、可验证跑步历史和用户目标/限制/可训练时间；总结读取本期全部运动、至多四份完整成功历史及本次固定计划。
- 总结包含核心结论、全运动统计、最多三项有来源跑技、其他运动说明/不确定性、简短计划对比、固定七日计划和数据局限/安全。
- 完整目的、剂量、步骤/重复组、RPE、技术备注和停止条件；休息不建Workout。
- 跑步硬负荷最多三次、日期差至少三天；不因攀岩改课，不强制SOS，不每日动态替换或补课。
- 有来源历史心率/session分区时长可展示；不得生成BPM、最大心率、阈值或分区处方。运动表现不是健康诊断。
- 有来源运动GPS/地点可保留；不得出现凭据、原始FIT字节、无关身份或主机文件路径。
- 同一验证修订生成中文Markdown/PDF和课程，summary不得生成第二份计划。
