测试不按文件年代、M12 前缀或固定总数决定去留。

包括参数化定义、原 SHA、当前要求、保留／迁移／取消／待迁移、新节点和退出任务。
这是一份迁移盘点，不是独立验收通过证明。

| 清单状态 | 含义与退出条件 |
| --- | --- |
| retain | 当前仍适用；继续执行正确断言 |
| migrate | 已找到当前实现路径的测试；仍需完整门与独立验收 |
| cancel | 用户已取消对应业务，只保存原文与取消依据，不再要求旧业务可运行 |
| pending | 尚未由新能力接替，保留旧场景；指定模块完成迁移后退出，最迟 M12-0005 |

文件混合多类场景时逐项处理，不能把整个文件直接归为“旧的、不需要”。
不得用 skip、xfail、减弱断言或只选通过用例替代迁移。未来能力的拟议测试不等于现有覆盖。
