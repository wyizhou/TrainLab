# 模型子进程监督

这是 M12 的内部进程组件，不是 `weekly` 命令、完整 Codex adapter 或隔离沙箱。
它接在[一次性任务账本](model-job-ledger.md)后，由受信任的 Host 提供参数，
不允许模型提供命令、环境变量或工作目录。

## 职责

`model_process.execute` 只启动一次绝对路径程序，不使用 shell，不自动重试，
不读取或继承未列明的环境变量，关闭多余文件描述符，并创建独立 session（会话）。
它在同一线程中同时发送 Prompt、读取 stdout 和 stderr，避免大输入、大输出互相等待。

- Prompt 上限 16 MiB；默认 stdout 64 MiB、stderr 1 MiB，均为有界内存。
- `input_bytes` 是成功写入管道的字节数，不冒称远端模型已经收到或理解内容。
- 输出超限、输入未完整送入、非零退出、网络调用器自身退出或 Host 管道错误均不能变成成功。
- 原始 stdout/stderr 不做内容截断后继续成功；超限结果带明确错误码，保留预算内字节供私有诊断。
- 错误码不包含命令、目录、环境值或底层错误正文；对象的默认文本表示不展示原始流。

运行预算默认 600 秒，涵盖启动、输入传输和运行；另有默认 5 秒终止与确认预算。
Host 可为当前任务选择明确的正数预算，不承诺永久内核/硬件卡死时仍准时返回。
模型结束后的同步证据落盘由 adapter 负责，不在后台另开写线程，也不算作模型运行时间。

## 主进程退出并不等于子进程全部退出

实际 Codex 会为 MCP 创建另一个进程组，但仍属于同一 session。只杀主进程组不够。
主进程退出时，组件立即终止该 session 内所有遗留进程组，再排空已经写入管道的内容。
超时或错误也停止并复查整个 session。确认时只查询 PID、进程组、owner、状态和
`os.getsid(pid)`，不读取其他进程的命令或环境。其他独立 session 不受影响。
不使用 macOS `ps sess` 列判断归属：本机实测该列不能可靠表示 POSIX session ID。
僵尸进程已经不能执行工作，不把等待系统回收的僵尸误判成仍在运行。
终止信号遇到进程消失或 macOS 的僵尸组 `EPERM` 时，仍继续有界回收和存活复查；
它既不是成功证明，也不能单独说明仍有活跃进程。只有新检查确认全部停止才普通返回。

如果无法确认停止，抛出 `ProcessInterrupted`（`AdapterInterrupted` 的子类），
其中保留有界的私有 `capture`；账本保持未终态，重启只读恢复，不启动第二次模型。
该异常不是“明确失败可以重试”，也不能被普通异常捕获改成成功。

普通返回的 `ProcessResult` 只证明进程层终止及传输情况：

| 结果 | 含义 |
| --- | --- |
| `error_code=null` | 输入送完、输出未超限、程序退出 0、整个 session 确认停止；尚不代表 AI 结果有效 |
| 稳定错误码 | 已确认停止，但本次启动、管道或进程结果失败 |
| `ProcessInterrupted` | 无法确认停止；只能保留未终态及诊断，禁止自动重跑 |

## 尚未由本组件提供的能力

- 实际 Codex 参数、版本/能力绑定、Structured Outputs 与最终 JSON 校验；
- 用户级指令和 Skill 的读取隔离、模型网络及 MCP 权限边界；
- stdout/stderr 私有持久化、业务结果发布和训练安全判断。

这些由完整 adapter 和 Host 前后检负责，不能凭进程监督替代。
本组件支持具有 `/bin/ps` 的正常 macOS/Linux POSIX 主机和不脱离 session 的受信任子程序；
不支持 Windows，也不承诺控制主动创建独立会话的恶意或不兼容程序。
如果系统观察不可用，停止而不是假定结束。

## 验证

[合成回归](../tests/code/contract/test_m12_model_process.py)使用本地 Python 子程序，
覆盖输入/输出并发、超限、超时、管道失败、子进程遗留、有限系统观察失败、环境/描述符
隔离、实际未回收僵尸、信号拒绝后仍存活/无法观察及账本重放。
不会启动用户 Codex、读取私人配置或调用模型/业务服务。

仓库外公开诊断另使用本机实际 Codex、合成 FIT 和仅限 localhost 的假 Responses 服务；
经过本监督器进行工具往返、正常退出和超时检查。首次按单组监督时的提前停止误判证据
永久保留；不能拿那次正常退出结果证明超时也正确。诊断护栏并非可部署的完整 Launcher，
日志和捕获文件不进入 Git，macOS 诊断不能替代 Linux 动态验收。
