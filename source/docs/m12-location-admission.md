# M12 运动数据开放与测试迁移

当前默认版本为 [fit-summary-3](fit-time-bounds.md)，沿用下述 v2 位置、名称及隐私边界；v1/v2 仍按冻结版本读取。

2026-09-07，A-022/VC-004 只改变运动位置和名称的模型准入要求，不改变 FIT-only、周频率、
前四份完整历史、训练安全、模型/细读预算、发布和真实切换目标。大功能总览见根 [PLAN.md](../../PLAN.md)，当前验收证据和恢复位置见 [M12 执行计划](../../exec-plans/active/M12-fit-weekly.md)。

## 旧场景如何保留

| 原场景 | 新版预期及验证位置 |
| --- | --- |
| GPS、坐标点列、路线方位文本、活动名必须拒绝 | 用户明确改为允许；[新版输入测试](../tests/code/contract/test_m12_sports_input.py) 在目标、历史结论/目标/计划与实际 Fake 调用验证原内容保留 |
| 原周输入、路线碎片及隐私回归 | 旧节点不删除，旧 helper 明确选择 fit-summary-1，继续证明历史快照没有被静默升级；不是新入口的准入证明 |
| 密码、认证头、Token、无关身份、路径及 FIT 字节拒绝 | 同一原拒绝函数完整复用到 v2 的四入口、四生命周期；调用 0、无模型 intent、内容与 SHA 不变 |
| FIT/细读输出没有 GPS | 新版改为实际首尾坐标、时间、缺失及来源；不平均/插值。旧 parser 在解码阶段就忽略 GPS，保留旧去重和输出行为 |
| inventory 标准行只有 ID/日期 | 不变。名称在周证据的 capture 来源层提取，不修改旧同步合同或把名称塞入 FIT parse 身份 |
| v1 detail/table 与旧工具清单 | 版本化支持 v1/v2；旧证明只供原材料的本地恢复，不授权当前新启动 |
| 模型/Provider 成功后重放 | 单次意图和账本不变，升级、搬迁和重启不获得新额度或触发重跑 |

原始 1823 节点及其后 2537 节点基线保留；新增节点和变更映射以提交前实际收集及受审清单核对。
除本次明确更改的地理拒绝预期外，不删除、弱化、skip 或 xfail 适用场景。合成夹具错误如字段
必须单行而给了裸换行，只修正夹具使其满足原 Goal 格式，不扩张或绕过生产 Goal 解析器。
