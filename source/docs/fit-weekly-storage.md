# M12 独立运动存储基础

此模块是内部 Python API，尚不是已交付的同步/周报命令。默认正式实例尚未切换。
源码位于 `skills/_shared/fit_weekly/storage.py`，不导入旧 state、M9/M10/M11 Candidate 或
data-backup。当前四张表承载文件和不可变结果；同步日期、分页进度和动作状态由后续模块接入，
不把预留的 document 种类当作已经实现了周报或真实投递。

| 存储 | 当前职责 |
| --- | --- |
| fits | FIT SHA、字节数、相对路径；原始文件仅存私有 fits/ |
| activity_fits | 精确活动身份与 FIT 修订绑定；同一 FIT 不得属于两个活动 |
| parses | FIT + 解析器版本唯一，规范 JSON 与内容 SHA；不批量保存秒级点 |
| documents | 输入 SHA + 业务种类/逻辑键唯一，规范 JSON 与内容 SHA |

## 私有实例

调用者明确传入实例根；目录必须为当前用户所有且 0700，文件 0600，无链接。
初始化只能使用空目录；已有旧库/配置不能被覆盖。日常打开缺库时停止，不静默创建。
新库名为 `trainlab-fit.db`，相对 FIT 路径为 `fits/<sha256>.fit`。整体移动实例后仍可打开；
数据库中不保存本机绝对路径。新库自己的 writer.lock 串行化写入，不占用旧正式 state 锁。

所有受管连接确认外键和递归触发器；表/触发器/Schema 版本、integrity 和外键先通过再使用。
文件索引、解析和结果只能追加：同键同输入复用，内容变化要求新解析版本或新业务输入。
INSERT OR REPLACE 也不得覆盖现有记录。这里是运行账本，不声称防御恶意同 UID/root。

## FIT 与崩溃恢复

- 来源必须是 owner-only 普通文件，SHA 匹配，并经实际 fitdecode 验证 CRC、activity 类型和 session。
- FIT 原字节保留在本地，可能含 GPS；本模块**不提供 AI 输入接口**。后续解析/细读必须用
  白名单剔除 GPS、路线、名称、标识和原文件字节，不能将本地保存许可误当作模型传输许可。
- 先把 FIT 同目录临时文件写入、fsync、原子改名，再提交数据库索引。重复导入不覆盖文件。
- 文件完成而 SQL 尚未提交时崩溃，重放同一 SHA/身份导入可登记原文件，不再复制。
  复用路径仍重新 fsync 文件与目录，两个持久化确认完成后才能提交索引；任一确认失败则回滚。
- 有限写入/fsync/rename 错误不生成成功索引；残留 `.pending-*` 是失败证据，不能当作 FIT。
  完整闭包检查遇到它会停止；后续恢复工具需确认该失败，再处理残留，不无条件删除。
- 全量闭包核对文件集合、大小、SHA 和活动绑定；未知文件、缺失或漂移不会被当作正常数据。

验收只使用匿名且 CRC 有效的合成 FIT。真实历史导入、日期覆盖、同步状态和 Provider 预算
仍属于 M12-0002 后续子模块，不由本基础模块隐式执行。
