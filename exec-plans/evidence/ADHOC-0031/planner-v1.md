### 数据与依赖方向

- **Garmin 模块**唯一管理认证刷新、同步检查点及新原件；临时文件验证后原子安装，不改旧原件。远端活动ID仅用于去重/恢复，不能替代 FIT SHA。
- **FIT 仓储**唯一修改 activities/records；解析器产生 DTO，经仓储整场事务保存；查询器与 Web 不各写一套入库 SQL。初始化不得删报告。
- **报告仓储**唯一修改 activties_report/weekly_report；AI client 不连数据库、不读 FIT、不决定业务作用域。
- **Context**读取仓储、获批索引/资料以及对应会话；产出 messages、固定工具声明、可信执行环境（授权活动集合、统一T、容量、预算句柄）。可信环境不由模型参数提供。
- **AI client**接收 messages 与注入的 dispatcher，处理兼容 API/工具协议，回传最终文本或明确错误；不在传输模块拼运动角色/七日窗口。
- **宿主编排**捕获 T、建立一致数据视图和权限，调用 Context→AI→报告仓储；Web routes 和定时入口均经该服务，不直连 Provider。
- **私有控制状态**拟放 `states/runtime/`：下载检查点、锁、预算账本、同步状态、会话；不是第五张业务表，不存被否决模型/版本/质量列的影子副本。只存完成运行所必需的操作状态，权限0700/0600，原子落盘和恢复校验。
- **业务DB**固定为 `states/data.db`；四张表和列严格不变。开发、Validator 与本地协议集成都显式使用隔离实例，不默认连正式 states。

### 4.1 解析、重复与时间

0024-T1 冻结一份公共 JSON Schema：standard 按消息/字段身份保存值和单位；developer 用开发者来源、消息、字段编号组合身份，不用同名覆盖。字典可放 sensors_json，records 返回附最小共用字段字典，不公开设备序列号；相对时间的原值/单位/语义放 metrics_json，UTC 不可确定为 null。实际0、类型规定的 invalid、缺字段、未知字段与解码损坏分开；未知标准字段保留编号和原始语义证据，不猜测运动指标。原生 lap/split/set 保留顺序/类型/单位，不混加、不猜训练阶段。

优先评估固定版官方 FIT Python SDK；必须用合成文件验证消息流顺序、Definition变化、链式片段、Developer/组件来源、CRC与错误列表，不能仅因参考资料写过包名就认为库满足完整记录目标。所有受支持单项运动按实际session处理；多运动不可用第一session冒充running，铁三不入分析作用域。SDK若丢未知字段/顺序，先修适配层或报告能力阻塞，不裁范围换通过。

零record：必须区分文件结构缺失与合法采样缺失。严格 Activity 必需消息缺失返回结构错误；保留真实record消息中合法可选值缺失。数据库里存在经获批完整性政策认可的零记录活动时查询返回空数组；不能将“无活动”也变为空数组。若准备允许零record FIT入库，0024-T1须根据固定SDK和协议证据明确合法例外，无法证明则失败，不杜撰数据。

同字节导入幂等，不因别的文件名增行。首版已有有效 SHA 行不自动重解析覆盖；手工重解析须维护窗口，失败保留旧行和报告。不用 REPLACE 引起外键级联。不同字节即不同ID，不自动合并/删除；同一远端活动再次导出字节变动标冲突，保留原件、停止自动导入该冲突项。其他来源疑似重复只提示/要求处理，不悄悄双计到周分析。

活动报告建议 activity_id 主键/外键，重复自动请求返回已有报告，明确“重新生成”成功后事务替换当前全文，失败保留旧报告；不承诺历史多版本。周报告每次显式新运行新增自增ID，同T允许多份；进程内相同请求不重复保存，提交结果不明时不自动重做收费或插入，返回不确定并核对，不能靠T唯一化或虚构跨崩溃 exactly-once。

### 4.2 AI工具、预算和一致性

records 的唯一参数/只读/全量/真实running及宿主授权集合均不变；不把浏览器活动搜索变成 AI 任意数据工具。工具参数严格 Schema、拒绝额外键、未知函数和坏 JSON。read_reference 若获批，只接受枚举 ID，映射到固定普通公开文件；拒绝绝对路径、遍历、符号链接逃逸、URL和随意跟随Markdown链接；可读列表不来自模型任意扩展。README是提示信息，真实权限由注册表执行。

正常流程：调用模型→保存 assistant tool_calls→逐个按 call_id 执行固定工具→回传对应 tool 消息→继续模型；直到返回无工具调用的完整最终文本。多工具请求串行执行和计费；工具输出是对象，按协议序列化一次，不双编码。finish_reason=length、响应不完整、无有效文本、未知工具、越权、超限、认证/网络失败都不是成功总结，不保存半份报告。可恢复工具错误按固定协议交模型处理，但仍计入循环上限；权限/资源/全局预算错误建议立即失败闭环，不要求无限循环到成功。

主 Agent 可冻结保守、可配置的容量默认值（例如每流程最多8轮模型请求、16次工具派发、总耗时180秒），不得视为已批准无限成本许可。实际字节/输入token/输出token限额依模型配置与预留量计算；未知容量或估算不可靠时明确拒绝，不能默认模型无限大。上下文包含完整获选默认数据、所需历史和工具结果；超限整体失败，引导用户开启新会话或选择容量更大的配置，不静默截断历史/records/总结。

周累计20次 records 边界继续保留。建议可信账本保守实现为实例级滚动七天最多20次非缓存采样派发（失败尝试也计，已授权同请求相同ID缓存命中不重复执行）；具体旧周口径未在首发材料冻结，此是待主 Agent 审核的更保守实现，不宣称旧规则原来就是滚动七天。原子预占预算再派发，重启/并发不重置；状态损坏或时钟倒退 fail closed。资料工具不消耗 records 专项配额，但计入通用调用/费用/容量限额。缓存命中仍先校验当前授权，不让历史缓存变成越权通道。

同一 AI 流程使用只读 SQLite 事务一致视图，缓存范围仅当前请求；读权限与数据共同绑定该视图。建议首版单进程、单调度器、显式串行写入和有限busy timeout，AI流程期间写事务排队（有界等待）；不跨 Provider 长期持有写事务。优先使用普通rollback journal，先不启用WAL，不对活库使用immutable。跨重启不复用旧缓存；恢复会话建立新视图和新授权。预算账本与会话文件分别加锁，不用业务数据库新列解决运行控制。

FastAPI lifespan启动/关闭Python定时器，单worker持有实例锁；启动时按持久 next_due 判断是否到期，停机错过多个周期合并为一次检查，不突发补跑。不要求额外安装系统自启服务。每三小时的间隔需假时钟测试，休眠唤醒/时钟变化不重复并发。

首次范围经D31-01确认后完整分页；固定本轮上界、重叠回看与远端ID去重，不能只取第一页或最大ID就认为没有新活动。检查点区分已发现待下载、原件已安装、待解析/失败；只有整页枚举完成后推进枚举位置，待处理项持久保存，重启重新枚举重叠页以修复分页移动。没有可靠稳定分页时，窗口内全分页扫描去重优先，不承诺任意年代的迟到数据都能由有限回看发现。

下载写私有临时文件，限制压缩/解压字节、文件数、总耗时；校验响应类型、ZIP目录成员及FIT完整性，再计算实际字节SHA并原子安装。ZIP禁止绝对路径、..、符号链接/硬链接、重复危险成员和压缩炸弹，不通用extractall。中断不留下最终文件假成功。一个archive含多个FIT时逐个校验，不默默只取第一个；远端ID与多个哈希关联由私有检查点表示。

认证文件只由一个适配器读写；实际格式待获准读取后核对 pygarminconnect 支持接口。失效可刷新时仅尝试有界刷新，临时新认证校验成功再原子替换，权限0600；并发锁、防符号链接/TOCTOU保护，不覆盖最后有效凭据、不输出内容。刷新失败/MFA需要人工则状态为AUTH_REQUIRED，暂停联网；不得静默切换外部CLI。状态显示最近尝试/成功/下次时间、新文件数、解析成功/失败和脱敏错误，不把“下载完成”等同“解析成功”。

### 4.4 HTTP/API建议

| 端点 | 输入/输出与所有权 |
| --- | --- |
| GET `/api/health` | 服务/构建/AI是否配置的布尔状态，不返回密钥或base_url凭据 |
| GET `/api/sync/status` | Garmin状态DTO；最后尝试/成功/下次计划与下载、解析阶段 |
| GET `/api/activities?q=&sport=&from=&to=&page=&page_size=` | 参数化搜索、稳定排序、有限页长；返回列表DTO，不含fit_path/原件或秘密 |
| GET `/api/activities/{activity_id}` | 基本/摘要/分段/非敏感字段说明；JSON解码为对象 |
| GET `/api/activities/{activity_id}/records` | 若开放Web明细，复用同一授权只读服务，只有ID、全量或明确失败，不另加records分页 |
| GET `/api/reports/activities/{activity_id}` | 活动全文总结，未生成404；不以FIT摘要代替 |
| GET `/api/reports/weekly?q=&page=&page_size=`、GET `/api/reports/weekly/{id}` | 周报列表搜索/全文；列表分页不改变AI工具全量语义 |
| POST `/api/reports/activities/{activity_id}/generate`、POST `/api/reports/weekly/generate` | D31-03确定后启用；当前对话/可选conversation_id，返回正文/报告ID或明确错误；宿主决定T和授权集合 |
| POST `/api/conversations/{id}/messages` | 在已绑定模式/对象下继续问答，不能用会话ID指定任意活动/DB/角色 |
| DELETE `/api/conversations/{id}` | 仅D31-03选持久会话时的显式删除；不级联删除业务报告 |

不额外建设通用任务队列/账号/上传/任意SQL API。长生成首版可受控异步处理但HTTP等待有限时间；断连/提交不确定错误有明确状态，不自动重复收费。日报模式定义相同Context接口但返回 NOT_IMPLEMENTED，入口无Provider副作用，页面标“后续接入健康数据”。

错误DTO统一 code/message/脱敏details；400/422参数错、404不存在、409冲突或缺报、413容量、503无配置/依赖不可用、502上游异常；不返回堆栈、凭据、原始私人请求。搜索范围首版覆盖运动类型/日期/已解析可展示文本及总结正文，不增加语义向量检索。

服务只绑定127.0.0.1:8080（需要IPv6时单独验证::1），不bind 0.0.0.0。Host白名单、同源CORS，写入入口检查Origin/Fetch元数据及JSON内容类型，拒绝外站驱动本地收费/同步；不把无认证等于无CSRF/重绑定防护。仅web目录静态服务，`/api`未知路由保持JSON404，缺失静态资源404，只有合法前端导航才SPA fallback。React按文本展示FIT字符串与AI报告；如渲染Markdown禁原始HTML并清理危险URL，不使用不受控innerHTML。无需开放states下载路由。
