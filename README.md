# TrainLab development repository

This repository separates development governance from the product runtime:

- Root `AGENTS.md`, `rules.md`, `memory.md`, `PLANS.md`, and
  `docs/exec-plans/` form the agentForge development Harness.
- `product/` is the sole TrainLab source, test, runtime-Harness, and local
  runtime root.
- `dist/` is generated by `tools/build_product.py` from an explicit allowlist.

Product development commands run from `product/`:

```sh
cd product
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m pip install -e .
.venv/bin/python -m pytest
```

Private state, configuration, logs, raw provider data, FIT files, databases,
and credentials remain local under `product/` and must never enter Git or
`dist/`. See `product/README.md` for product architecture and operations.
