# v3.1 设计文档 — TrainLab 完整参数交底

日期:2026-07-14 · design_rev 4 · 源原型:`运动分析系统.dc.html`(导出副本 `design/v3.1/运动分析系统.dc.html`)

## 权威性声明(取代 v3.0 表述)
本文档的 token 表为 TrainLab 视觉参数的**唯一事实源**。实现须 **1:1 对齐本表 computed 值**——此为让实现忠实于未改动的原型,属**实现对齐,非设计变更**。v3.0 中"色板/间距 token 以 v2.0 为准""无 token 值变更"等表述作废;不再将 v2.0 实现 token 当权威来源。

## 取值口径
- 值取自浏览器实际渲染的 **computed 值**;颜色以 rgb/rgba 记录,hex 为等值换算。
- 采集视口:wide(1593px)、tablet(873px)登录后逐屏实采;标「实测」。
- mobile(<640)与部分 tablet 专属分支值由组件逻辑 `bp/isMobile` 决定,未在该视口实采者标「待渲染确认」并注明——因当前预览视口无法由本工具主动缩放到 <640,mobile 专属值需下游在 390px 视口自测复核。
- 全部行内样式,无影响这些属性的 CSS 类(仅 body reset + @keyframes);computed 值即契约值,`support.js` 不注入样式。

## 断点定义
mobile < 640 / tablet 640–979 / desktop 980–1439 / wide ≥ 1440。

### §A 范围与例外声明(令"全部引用 token"成立)
颜色 / 圆角 / 间距三类属性,§A 已全部引用表 (a)(b)(c) token,无脱管裸值。以下两类**本版范围外**,§A 中以字面值出现属**显式例外**,非无声裸值:
- **Typography(字号/字重/行高)**:如 font-size 13px/11px、font-weight 600/700 等,本版未纳入 token 化,留待后续版本补齐 typography 档位;当前以字面 computed 值记录。
- **固定结构尺寸(width/height/min-width/border-width 等)**:如 session-rail width 212px、bottom-nav height 60px、modal width 390/620px、settings-page max-width 760px、analysis-main max-width 1200px、activities-table 内层 min-width 960px、边框宽度 1px/2px/3px 等,为逐元素结构测量值,本版以字面 computed 值内联记录,不纳入 token 表。

## §B 交互契约

本设计**不使用 CSS 状态类名**;状态由 React state 标志驱动行内样式切换。下游以 state 标志 + `data-vc` 锚点为抓手。

- I-nav:点 `top-nav-item*`/`bottom-nav-item*` → 切主标签、清详情;当前项 active 配色。`state.tab`。
- I-health-tab:点 `health-tab*` → 切健康子视图(睡眠/体重/静息心率/HRV/习惯)。`state.healthTab`。
- I-scope:点 `scope-chip*` → 设范围天数、清已勾选运动;当前转 selected。`state.rangeDays`/`state.picked`。
- I-type:点 `type-chip*` → 过滤列表、复位分页。`state.actFilter`。
- I-card(四态):点 `chart-card` 头部(cardReady)→ 折叠⇄展开(`msg.expanded`);明细行仅 desktop/wide(showCardRows);回复到达先 cardLoading(shimmer+spin)~1100ms 转 cardReady;范围内运动<2 次为 cardEmpty 不可展开。
- I-session:点 `session-rail-item*` 主体切会话(`state.curSession`);✎ 行内重命名 Enter 确认/Esc 取消(`state.renamingId`);✕ 删除(删当前跳首个,删空自动新建);「+ 新建会话」新增并切换。
- I-send:点 `btn-primary` 或输入区 Enter(Shift+Enter 换行)→ 追加用户气泡+typing 指示,~1400ms 出 AI 回复(带 I-card)。`msg.typing`。
- I-connector-sync:点「立即同步/重试同步」→ syncing(spinner)~1600ms → 转 connected、更新时间与计数。`connector.syncing`/`connector.status`。
- I-connector-auth:点「连接账号」→ 开 `modal-connector-auth`;勾 2FA 两阶段(提交账密→出 6 位码框→再提交)。`connModal.stage`('cred'→'code')。
- I-conflict:点冲突横幅「处理重复」→ 开 `modal-conflict`;逐组选保留 CN/国际区 →「确认合并」。`state.conflictOpen`/`state.conflictChoices`。
- I-hover:`session-rail-item*` 与运动桌面表格数据行 hover 底 {hoverRow}(行内 style-hover,非 :hover 类)。
- I-view-toggle:点「图表(降采样)/逐秒数据表」→ 切 `state.detView`;选中段 background {accent@0.16}+border {accent}。
- 非契约:异步时长(1100/1400/1600ms)为模拟值,非性能契约。
