# v3.0 设计文档 — TrainLab 视觉契约(保真交接)

日期:2026-07-13 · design_rev 3 · 源原型:`运动分析系统.dc.html`(导出副本 `design/v3.0/运动分析系统.dc.html`)

本版无任何视觉设计变更,仅把 v2.0 的隐式视觉/布局契约显式化。视觉设计以 v2.0 设计文档为准(色板/字号/间距 token 见 `v2.0-设计文档.md` §1)。本文只做两件事:(A) 逐 `data-vc` 锚点列出「真正定义长相且可能被搞错」的契约属性;(B) 交互契约。

## 取值口径
- 除标注外,契约属性值取自浏览器实际渲染的 **computed 值**(渲染视口 1593px,属 wide 断点;登录后逐屏采集)。颜色为 computed 后的 rgb/rgba。
- 断点差异中,桌面/宽屏值为实测;`tablet(640–980)`、`mobile(<640)` 专属值标注为「源码 authored」——由组件逻辑中 `bp/isMobile` 分支决定,渲染于对应视口时生效,下游可在该视口自测复核。
- 本设计全部使用行内样式,页面无影响这些属性的 CSS 类规则(仅 body reset 与 @keyframes),故 computed 值即契约值,无层叠覆盖风险;`support.js` 不注入样式,仅承载运行时状态。
- 标「待渲染确认」者为未在对应视口实采、仅依据源码推断的值。

## 断点定义(沿用 v2.0)
mobile < 640 / tablet 640–979 / desktop 980–1439 / wide ≥ 1440。

## B. 交互契约

本设计**不使用 CSS 状态类名**;所有状态(展开/选中/加载/同步中/弹窗阶段)由 React state 标志驱动行内样式对象切换。下游镜像实现时应以 state 标志 + `data-vc` 锚点为抓手,而非查找类名。

- I-nav:点击 `top-nav-item*` 或 `bottom-nav-item*` → 切换主标签、清空运动详情;当前项转 active 配色。状态 `state.tab`。
- I-health-tab:点击 `health-tab*` → 切换健康子视图(睡眠/体重/静息心率/HRV/习惯)。状态 `state.healthTab`。
- I-scope:点击 `scope-chip*` → 设定数据范围天数并清空已勾选运动;当前胶囊转 selected。状态 `state.rangeDays`/`state.picked`。
- I-type:点击 `type-chip*` → 过滤运动列表并复位分页。状态 `state.actFilter`。
- I-card(图表卡片四态):
  - 触发:点击 `chart-card` 头部行(cardReady 态)→ 折叠 ⇄ 展开。状态 `msg.expanded`(true=展开)。
  - 展开态明细行:仅 desktop/wide 渲染(showCardRows);tablet/mobile 只有轴说明+图表。
  - 加载态:回复到达后卡片先 cardLoading(shimmer+spin),约 1100ms 后转 cardReady。
  - 空态:范围内运动 < 2 次时为 cardEmpty,不可展开。
- I-session:
  - 点击 `session-rail-item*` 主体 → 切换当前会话。状态 `state.curSession`。
  - 点击项内 ✎ → 行内重命名(出现 input);Enter 确认、Esc 取消。状态 `state.renamingId`。
  - 点击项内 ✕ → 删除会话(删当前则跳第一个,删空自动新建)。
  - 「+ 新建会话」→ 新增并切换。
- I-send:点击 `btn-primary`(发送)或输入区 Enter(Shift+Enter 换行)→ 追加用户气泡 + AI typing 指示,约 1400ms 后出 AI 回复(带 I-card 流程)。状态 `msg.typing`。
- I-connector-sync:点击「立即同步/重试同步」→ 按钮进入 syncing(spinner)约 1600ms → 转 connected、更新时间与计数。状态 `connector.syncing`/`connector.status`。
- I-connector-auth:点击「连接账号」→ 打开 `modal-connector-auth`;勾选 2FA 时两阶段(第一次提交验证账密→出现 6 位验证码框→再次提交)。状态 `connModal.stage`('cred'→'code')。
- I-conflict:点击冲突横幅「处理重复」→ 打开 `modal-conflict`;逐组选保留 CN/国际区 →「确认合并」。状态 `state.conflictOpen`/`state.conflictChoices`。
- I-hover:
  - `session-rail-item*` hover 背景 rgb(22,32,47)#16202F(style-hover)。
  - 运动记录桌面表格数据行 hover 背景 #16202F(带 F0 alpha)。
  - 说明:hover 为行内 style-hover,非 :hover 类。
- I-view-toggle(运动详情时序):点击「图表(降采样)/ 逐秒数据表」→ 切换 `state.detView`('charts'/'table');选中段 background rgba(66,146,224,0.16)+border #4292E0。
- 非契约:各异步时长(1100/1400/1600ms)为原型模拟值,非产品性能契约。
