# v1.0 设计文档 — TrainLab 运动数据分析系统

日期:2026-07-10 · design_rev 1 · 文件:`运动分析系统.dc.html`(历史版本快照见 `归档/`)

> 本文档为首个统一版本,合并了此前 v0.1.0 / v0.2.0 的全部内容并覆盖最新信息架构。变更清单各行索引到下方章节。

## 0. 核心理念与设计原则(清单 #1)
1. **系统只存储原始数据**:运动 record 流、健康记录、习惯因子、FIT 内设备原始存储值。TSS、训练负荷、CTL/ATL/TSB 等衍生指标全部由 AI 分析在对话回复中产出并注明计算依据,界面上没有任何系统预计算的常驻指标卡片。
2. 受众为有 2 年以上数据的严肃耐力训练者:高密度、精确、无引导式教学。
3. 强调色 `oklch(0.65 0.15 230)`(#4292E0)为稀缺资源:仅主操作按钮、当前选中态、图表主数据序列。
4. 数字一律等宽(全局 `font-variant-numeric: tabular-nums` + 数值列 ui-monospace),列表数字竖向对齐。

### 视觉 tokens
- 背景 #0A0F18 / 面板 #121A28 / 深面板 #0B1220 / 边框 #223049、#1C2739 / 输入边框 #2A3A55
- 文本 #E6EBF4,次级 #8A94A8,弱化 #5C687E,禁用 #3A4457
- 语义色:成功 #3FBF8F,警示 #E0A040,错误/心率 #E06060,HRV 紫 #9B7BE0
- 运动类型色:跑步蓝 / 骑行绿 / 游泳青 / 力量橙 / 越野紫
- 圆角:面板 12px、控件 8px、胶囊 99px

### 信息架构
顶部导航(桌面+平板,平板缩小间距/字号并隐藏同步胶囊):**分析(默认)/ 运动记录 / 健康记录 / 连接器 / 设置**;登录页独立。习惯记录是健康记录的子标签页;文件上传是连接器页的组成部分。

## 1. 登录(清单 #2)
居中卡片,无营销元素:用户名 / 密码 / 4 位验证码(点击刷新),错误提示,回车提交。演示规则:任意用户名 + ≥4 位密码 + 正确验证码。

## 2. 分析页 — 产品核心(清单 #3–#6)
### 2.1 会话(#3)
- 桌面:左侧 212px 会话栏 —— "+ 新建会话"主按钮、会话项(名称 + 消息数,选中态左侧强调色条)、悬停显示 ✎ 重命名(行内输入,Enter 确认/Esc 取消)与 ✕ 删除(删除当前会话则切到第一个,删空自动新建)
- 平板(<980px):会话栏降级为顶部下拉选择 + 新建按钮

### 2.2 数据范围选择器(#4)
- 3(默认)/7/15/30 天胶囊;"选择运动 (n)"展开可勾选列表(勾选后覆盖时间范围)
- "附带健康记录"、"附带习惯记录"两个开关,默认均勾选
- 底部实时显示当前范围摘要

### 2.3 图表卡片四态(#5)
嵌在 AI 回复气泡内,深色内嵌容器(#0B1220 + 边框):
- **加载态**:spinner + "正在读取原始数据并生成图表…",整行 shimmer 呼吸动画;回复文本先到,约 1.1s 后卡片就绪
- **空态**:范围内 <2 次运动时触发 —— ▦ 图标 + "数据不足,无法生成图表" + 原因说明 + 操作建议,不可展开
- **折叠态(默认)**:📊 + 标题 + 一行等宽摘要(如 "最近 7 天 · 5 次运动 · 平均 146 bpm · 区间 132–158")+ "展开 ▼"
- **展开态**:轴说明行(Y:bpm · X:日期)+ 340×112 折线图(Y 轴 3 档刻度、X 轴首/中/末日期刻度)+ 逐条数据行;**平板降级:隐藏数据行,只保留图表**
- 视觉层级:用户消息(实心蓝 #2E5C9E,右对齐)> AI 回复(面板色气泡,左对齐,最小宽 46%)> 图表卡片(气泡内再下沉一层)

### 2.4 AI 回复与隐藏提示词(#6)
- AI 回复为 HTML 渲染:分析类含运动数据表格 + 有序结论;含"计划"的提问输出 7 天课表表格;附带健康/习惯时追加对应解读段落
- 隐藏系统提示词(随每次请求发送,不显示在对话流):强制内联样式 HTML 回复、仅基于附带原始数据、衍生指标由 AI 计算并注明依据、数据不足返回空态、中文+英文缩写;设置 → AI 接口可查看/收起

## 3. 运动记录(清单 #7、#8)
### 3.1 列表(#7)
复选框 / 日期 / 类型色点 / 名称 / 距离 / 时长 / 平均心率 / 配速或功率 / 来源(佳明CN、佳明国际、FIT上传)/ 单条 FIT 下载;类型筛选胶囊(全部/跑步/骑行/游泳/力量/越野跑);批量"下载选中 FIT (n)";分页 20(默认)/50/100。

### 3.2 详情(#8)
- 字段集 = **用户真实 FIT(614797758_ACTIVITY.fit,@garmin/fitsdk 解析)∩ 佳明 Connect 详情页**;列表第一条"晨间轻松跑"即该文件真实数据
- 指标分区(各区标注 FIT 字段名,无数据 "--"):计时 / 配速速度 / 心率 / 功率(含 NP®)/ 跑步动态 / 踏频 / 训练效果(FIT 原始存储值,非系统计算)/ 海拔 / 温度 / 卡路里 / 自我评价 / Connect IQ 开发者字段(GCT、V.OSC、LSS、V.ILR、Body Y PIF 等)
- **时序数据双模式**:
  - 图表(降采样):逐秒 record 流降采样 56 点;跑步 8 张(配速/心率/功率/步频/海拔/温度/触地时间/垂直振幅)、骑行 6 张、游泳 2 张、力量 1 张;每张 Y 轴 3 档刻度 + X 轴 5 档时间刻度 + 来源字段标注
  - 逐秒数据表:完整 record 流(时间/距离/配速或速度/心率/功率/步频或踏频/海拔/温度),分页 20/50/100,行数 = 运动秒数
- 心率区间时间条形图(time_in_hr_zone):Z1–Z5 边界取自设置页"区间设定"
- 分段 Laps 表(含平均功率列);"下载 FIT 文件"主按钮

## 4. 健康记录(清单 #9)
五个子标签页,均为设备原始值:
- **睡眠**:近 14 天深/浅/REM 堆叠柱 + 明细表(含静息心率)
- **体重**:近 30 天曲线 + 明细表(体重/体脂率/肌肉量/体水分)
- **静息心率**:近 30 天曲线(resting_heart_rate)+ 明细表(静息/夜间最低)
- **HRV**:近 30 天夜间曲线 + 明细表
- **习惯**:日期选择(默认当天)+ 已记录计数;早上/中午/晚上/全天四组因子胶囊勾选(咖啡、运动强度、看书、午睡、酒精、熬夜、久坐等),按日期存储,供 AI 作关联因子
- 表格统一分页 20/50/100;数据量级 90 天

## 5. 连接器(清单 #10–#13)
### 5.1 连接器卡片状态集合(#10)
已连接(绿胶囊)/ 未连接(灰胶囊 + "连接账号")/ 同步中(按钮 spinner)/ **同步失败**(红胶囊 + 红色错误块:失败时间 + 原因,按钮变"重试同步");显示上次成功同步时间、已同步数量、自动同步间隔(30 分钟/1 小时/6 小时/仅手动)。演示初始态:中国区为同步失败(ETIMEDOUT),国际区未连接。
### 5.2 授权登录弹窗(#11)
账号 / 密码 / "启用了 2FA"勾选。未勾选:一次登录接入;勾选:第一次登录验证账号密码 → 出现 6 位验证码输入区(2FA 勾选锁定)→ 再次点登录后台验证。校验与 busy 态齐全。
### 5.3 双账号合并(#12)
规则:按「开始时间 + 时长」自动去重,来源标注保留。无法自动判定 → 页顶警示横幅"发现 n 组疑似重复运动" + "处理重复"按钮 → 弹窗逐组选择"保留中国区 / 保留国际区" → 确认合并。演示:连接国际区后出现 2 组冲突。
### 5.4 文件上传(#13)
本页内上传区:FIT/TCX/GPX 多选、≤50MB;"已解析文件"列表(名称/大小/时间/已入库);入库后出现在运动记录,来源"FIT上传"。

## 6. 设置(清单 #14)
1. **账户信息**:用户名 / 昵称 / 新密码×2(一致性校验)
2. **单位制**:距离海拔(公制/英制)、配速(min/km / min/mi)、体重(kg/lb)
3. **区间设定**:最大心率、LTHR、FTP + Z1–Z4 心率上界;仅作原始数据标注边界(详情页心率区间图)并随 AI 对话附带,系统不用于计算
4. **数据保留策略**:占用统计;原始 FIT 保留期限(永久/24 个月/12 个月)+ 到期自动清理开关(摘要行保留)
5. **AI 接口**:base_url(默认 https://api.deepseek.com)/ API Key / 模型名(deepseek-chat / deepseek-reasoner 提示)/ 测试连接识别模型 / 隐藏系统提示词查看

## 7. 响应式(平板 <980px)
- 顶部导航缩小内边距与字号,隐藏"上次同步"胶囊,可横向滑动(隐藏滚动条)
- 分析页:会话栏 → 下拉选择;图表卡片展开态隐藏数据明细行,只保留带轴标签的图表
- 各表格容器横向滚动,最小宽度保护列对齐

## 8. 演示数据说明
约 70 条运动(近 180 天)、90 天健康数据、3 天习惯记录均为假数据;运动记录第一条为真实 FIT 解析值。同步、下载、AI 回复、API 测试均为前端模拟。

## 9. 遗留建议
- FIT 含经纬度流,轨迹地图未展示
- 习惯因子为预置清单,未支持自定义管理
- AI 对话未接真实 API(设置页配置已就位)
