## 2. 断点矩阵与全局行为(清单 #1、#3、#4)

断点(window.innerWidth):**mobile < 640 / tablet 640–979 / desktop 980–1439 / wide ≥ 1440**。基准视口:390×844 / 768×1024 / 1280×800 / 1920×1080。

| 元素 | mobile | tablet | desktop | wide |
|---|---|---|---|---|
| 顶部导航项 | 隐藏(display 无该 nav) | 显示,项 padding 7px 9px、12px | 显示,8px 13px、13px | 同 desktop |
| 底部 tab 栏 | 显示:fixed bottom,高 60px,bg #0D1420,上边框 1px #1C2739,5 项等分;选中项文字 #5EA3E8 + 上边框 2px #4292E0,未选中 #8A94A8 | 隐藏 | 隐藏 | 隐藏 |
| 「上次同步」胶囊 | 隐藏 | 隐藏 | 显示 | 显示 |
| 主内容 padding | 14px 12px 76px | 18px 16px | 22px 24px | 22px 24px |

可断言判据:
- 390px:`nav.top-nav` 不存在于 DOM;底部存在 `position:fixed;bottom:0` 高 60px 的 nav,子项 5 个。
- 768px:top-nav 存在;同步胶囊不存在;底部 tab 不存在。
- 1280px:同步胶囊存在(文本以"上次同步"开头)。
- 所有断点:`document.documentElement.scrollWidth <= window.innerWidth`(无横向溢出)。

## 7. 设置(清单 #12、#13)
